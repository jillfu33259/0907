# CAPTAIN'S ROOM — 盧廣仲宇宙

一個非官方的盧廣仲歌迷平台，提供授權 30 秒歌曲試聽、影視作品精選、冷知識與成長年表。

## 本機預覽

直接用瀏覽器開啟 `index.html`，或啟動任意靜態伺服器。

## 部署至 Render

1. 在 Render 選擇 **New → Static Site**，連結此 GitHub repository。
2. Render 會讀取 `render.yaml`；若需手動填寫，Build Command 留空、Publish Directory 填 `.`。
3. 完成部署即可取得公開網址。

歌曲使用 Apple iTunes Search API 的官方 30 秒 preview URL；完整版會依播放地區與服務提供狀況而定。
